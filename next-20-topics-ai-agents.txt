ĐỊNH HƯỚNG CHUNG:
- Chuyên sâu về AI Agents, công cụ và ứng dụng thực chiến
- Nhắm đến các role IT cụ thể: Sales, PM, Developer, BrSE, QA, DevOps, Architect
- Kết nối lý thuyết với thực tế công việc hàng ngày
- Xây dựng trên nền tảng đã có: BMAD, MAS, M365 Copilot, Claude Code, Superpowers

====================================================================
NHÓM 1: AI AGENTS CHO DEVELOPER & ARCHITECT (Bài 18–21)
====================================================================

Bài 18:
  Tiêu đề: Cursor AI vs Claude Code vs GitHub Copilot: Đâu là "Coding Agent" tốt nhất cho Developer Việt Nam?
  Mô tả: So sánh chi tiết 3 công cụ AI coding agent phổ biến nhất hiện nay theo các tiêu chí: tốc độ, độ chính xác, hỗ trợ tiếng Việt, tích hợp workflow, chi phí. Cung cấp bộ tiêu chí lựa chọn phù hợp từng loại dự án (startup, enterprise, outsourcing).
  Target role: Developer, Tech Lead, Architect
  Từ khoá: Cursor AI, Claude Code, GitHub Copilot, coding agent, so sánh AI IDE

---

Bài 19:
  Tiêu đề: Test-Driven Development với AI Agent: Viết Test trước, để Agent tự code
  Mô tả: Hướng dẫn áp dụng TDD (Test-Driven Development) kết hợp AI Agent — viết test case trước, sau đó dùng Claude Code / Copilot Workspace tự động sinh code thỏa mãn test. Giới thiệu workflow "Red-Green-Refactor" được tăng tốc bằng AI, kèm ví dụ thực tế với Jest, PyTest, JUnit.
  Target role: Developer, QA
  Từ khoá: TDD với AI, AI-assisted testing, Claude Code TDD, test automation agent

---

Bài 20:
  Tiêu đề: AI Agent cho Code Review: Tự động hóa quy trình review Pull Request với GitHub Actions + AI
  Mô tả: Xây dựng pipeline tự động review PR sử dụng AI Agent (CodeRabbit, Ellipsis, hoặc Claude qua API) tích hợp GitHub Actions. Hướng dẫn cấu hình rules, comment tự động, phát hiện bug logic và security issue trước khi merge.
  Target role: Developer, Tech Lead, DevOps
  Từ khoá: AI code review, CodeRabbit, PR automation, GitHub Actions AI, automated review agent

---

Bài 21:
  Tiêu đề: Thiết kế Hệ thống với AI: Dùng Agent để tạo Architecture Diagram, ERD và API Spec từ mô tả yêu cầu
  Mô tả: Hướng dẫn sử dụng AI Agent (Eraser.io AI, Mermaid AI, Claude) để tự động sinh System Architecture Diagram, Entity-Relationship Diagram và OpenAPI Specification từ một đoạn mô tả yêu cầu bằng tiếng Việt. Kết hợp với BMAD method để chuẩn hóa đầu ra.
  Target role: Architect, Tech Lead, Developer
  Từ khoá: AI system design, architecture diagram AI, ERD generator, OpenAPI agent

====================================================================
NHÓM 2: AI AGENTS CHO QA & TESTING (Bài 22–24)
====================================================================

Bài 22:
  Tiêu đề: Playwright + AI Agent: Tự động sinh và chạy End-to-End Test từ User Story
  Mô tả: Giới thiệu workflow kết hợp Playwright với AI Agent để tự động sinh E2E test script từ User Story hoặc Acceptance Criteria. Hướng dẫn dùng Claude / GPT-4o để phân tích story, tạo test cases và tự viết Playwright script, sau đó tích hợp vào CI/CD pipeline.
  Target role: QA, Developer, DevOps
  Từ khoá: Playwright AI, E2E test automation, AI test generation, QA agent

---

Bài 23:
  Tiêu đề: AI Agent cho Exploratory Testing: Chiến lược dùng LLM để tìm Bug mà Automation bỏ sót
  Mô tả: Phân tích giới hạn của automation testing và cách AI Agent bổ sung thông qua exploratory testing thông minh. Giới thiệu kỹ thuật dùng AI để sinh test idea đa dạng, mô phỏng hành vi người dùng bất thường, và phân tích log để xác định vùng rủi ro cao. Kèm ví dụ thực chiến với công cụ như Functionize, Mabl.
  Target role: QA, Test Lead
  Từ khoá: AI exploratory testing, LLM testing strategy, Mabl, Functionize, QA AI agent

---

Bài 24:
  Tiêu đề: Viết Test Case bằng Tiếng Việt, AI dịch và sinh Automation Script: Workflow cho BrSE và QA Offshore
  Mô tả: Giải quyết rào cản ngôn ngữ trong dự án offshore Việt-Nhật: dùng AI Agent để dịch test case tiếng Việt sang tiếng Nhật, đồng thời tự động sinh automation script (Selenium, Playwright) từ test case đó. Workflow thực tế cho BrSE làm cầu nối giữa khách hàng Nhật và team QA Việt Nam.
  Target role: BrSE, QA, Offshore Team
  Từ khoá: BrSE AI workflow, test case translation AI, offshore QA automation, Việt-Nhật AI

====================================================================
NHÓM 3: AI AGENTS CHO PROJECT MANAGER & SCRUM MASTER (Bài 25–27)
====================================================================

Bài 25:
  Tiêu đề: AI Agent cho Sprint Planning: Tự động phân tích Backlog, Estimate Story Point và Assign Task
  Mô tả: Hướng dẫn xây dựng AI Agent hỗ trợ Sprint Planning — tự động đọc và phân tích Product Backlog từ Jira/Linear, gợi ý Story Point dựa trên lịch sử sprint, phát hiện dependency và đề xuất phương án assign task tối ưu theo năng lực team. Tích hợp với Claude qua MCP connector.
  Target role: Project Manager, Scrum Master, Team Lead
  Từ khoá: AI sprint planning, Jira AI agent, story point estimation AI, backlog analysis

---

Bài 26:
  Tiêu đề: Meeting Intelligence với AI: Tự động ghi chép, tóm tắt và tạo Action Item từ cuộc họp dự án
  Mô tả: Workflow hoàn chỉnh dùng AI Agent (Otter.ai, Fireflies, hoặc Whisper + Claude) để ghi âm, phiên âm, tóm tắt meeting và tự động tạo Action Item có người phụ trách và deadline. Hướng dẫn tích hợp vào Slack, Teams, và Notion để đồng bộ thông tin dự án.
  Target role: PM, Scrum Master, BrSE
  Từ khoá: AI meeting notes, Fireflies AI, Otter.ai, action item automation, meeting intelligence

---

Bài 27:
  Tiêu đề: Risk Management với AI Agent: Phát hiện sớm rủi ro dự án từ dữ liệu Jira, Git và Slack
  Mô tả: Xây dựng AI Agent theo dõi "tín hiệu nguy hiểm" của dự án: số lượng bug tăng đột biến, commit giảm, comment Slack chứa từ khoá tiêu cực, task quá hạn. Agent tổng hợp và cảnh báo PM trước khi vấn đề leo thang. Kèm hướng dẫn cài đặt với n8n hoặc Make.
  Target role: PM, Delivery Manager, Scrum Master
  Từ khoá: AI risk management, project risk agent, n8n AI automation, Jira risk monitoring

NHÓM 4: AI AGENTS CHO BrSE (BRIDGE SYSTEM ENGINEER) (Bài 28–30)
====================================================================

Bài 28:
  Tiêu đề: BrSE 2.0: Dùng AI Agent để dịch thuật, làm rõ yêu cầu và viết Specification cho dự án Nhật
  Mô tả: Hướng dẫn BrSE xây dựng bộ công cụ AI cá nhân để: dịch tài liệu kỹ thuật Nhật-Việt với context chuyên ngành, tự động phát hiện điểm mơ hồ trong requirement, và sinh draft Functional Specification chuẩn theo format khách hàng Nhật. Sử dụng Claude với custom system prompt chuyên biệt.
  Target role: BrSE, Business Analyst
  Từ khoá: BrSE AI tools, kỹ thuật dịch thuật AI, requirement analysis agent, Nhật-Việt AI

---

Bài 29:
  Tiêu đề: Xây dựng Knowledge Base cho BrSE với AI: Lưu trữ, tìm kiếm và tái sử dụng kiến thức dự án
  Mô tả: Hướng dẫn BrSE xây dựng hệ thống Second Brain chuyên ngành sử dụng RAG (Retrieval-Augmented Generation): index toàn bộ tài liệu dự án (spec, email, meeting notes), rồi dùng AI để trả lời câu hỏi "Khách hàng đã quyết định gì về tính năng X?" trong vài giây. Công cụ: Obsidian + Local AI hoặc NotebookLM.
  Target role: BrSE, PM, BA
  Từ khoá: RAG cho BrSE, knowledge base AI, NotebookLM, Second Brain kỹ thuật

---

Bài 30:
  Tiêu đề: Onboarding Dự án Mới trong 1 Ngày với AI Agent: BrSE nắm bắt toàn bộ codebase và spec
  Mô tả: Chiến lược dùng AI Agent để rút ngắn thời gian onboarding dự án từ vài tuần xuống còn 1-2 ngày. AI phân tích toàn bộ codebase, sinh sơ đồ kiến trúc, tóm tắt spec quan trọng và tạo danh sách câu hỏi làm rõ cho khách hàng. Workflow thực tế cho BrSE tiếp nhận dự án brownfield.
  Target role: BrSE, Developer mới vào dự án
  Từ khoá: AI onboarding, codebase analysis AI, dự án brownfield AI, BrSE productivity

NHÓM 5: AI AGENTS CHO SALES & PRESALES IT (Bài 31–33)
====================================================================

Bài 31:
  Tiêu đề: AI Agent cho IT Sales: Tự động nghiên cứu khách hàng, tạo Proposal và cá nhân hóa Email tiếp cận
  Mô tả: Workflow AI hoàn chỉnh cho IT Sales: Agent tự động thu thập thông tin công ty khách hàng (ngành nghề, pain points, tech stack từ LinkedIn/Crunchbase), tổng hợp insight và sinh draft email tiếp cận cá nhân hóa + proposal sơ bộ. Công cụ: Clay, Apollo AI, hoặc tự xây với n8n + Claude.
  Target role: IT Sales, Presales, Business Development
  Từ khoá: AI for IT sales, sales automation agent, proposal generator AI, Clay AI

---

Bài 32:
  Tiêu đề: Estimate Dự án với AI: Từ Requirement mơ hồ đến Báo giá chính xác trong 30 phút
  Mô tả: Hướng dẫn dùng AI Agent để phân tích requirement từ khách hàng, tự động phân rã thành WBS (Work Breakdown Structure), estimate effort từng hạng mục dựa trên dữ liệu dự án lịch sử, và sinh báo cáo estimate có kèm contingency và risk buffer. Chuẩn hóa quy trình presales cho công ty IT outsourcing.
  Target role: Sales, PM, Presales, Architect
  Từ khoá: AI project estimation, WBS generator AI, presales automation, effort estimation agent

---

Bài 33:
  Tiêu đề: Dùng AI để Phân tích Đối thủ Cạnh tranh: Chiến lược Competitive Intelligence cho IT Company
  Mô tả: Xây dựng hệ thống AI Agent theo dõi và phân tích đối thủ cạnh tranh: crawl thông tin từ website, job posting, GitHub, LinkedIn; phân tích điểm mạnh/yếu; tạo báo cáo định kỳ hàng tuần. Áp dụng cho IT outsourcing company muốn định vị lại dịch vụ và giành thêm deal.
  Target role: Sales, Marketing, Business Development, C-level
  Từ khoá: competitive intelligence AI, market analysis agent, IT sales strategy AI

NHÓM 6: AI AGENTS & DEVOPS / PLATFORM ENGINEERING (Bài 34–36)
====================================================================

Bài 34:
  Tiêu đề: AIOps: Dùng AI Agent để Tự động Giám sát, Phân tích Log và Phản ứng Sự cố Hạ tầng
  Mô tả: Giới thiệu AIOps và cách xây dựng AI Agent giám sát hệ thống: tự động phân tích log lỗi, phát hiện anomaly, tìm root cause và thực hiện remediation action (restart service, scale up, rollback) với sự phê duyệt của human-in-the-loop. Công cụ: Datadog AI, Grafana + AI plugin, hoặc tự xây với LangChain.
  Target role: DevOps, SRE, Platform Engineer
  Từ khoá: AIOps, log analysis AI agent, incident response automation, Datadog AI

---

Bài 35:
  Tiêu đề: Infrastructure as Code với AI: Tự động sinh Terraform, Kubernetes YAML từ mô tả kiến trúc
  Mô tả: Hướng dẫn dùng AI Agent để sinh IaC (Infrastructure as Code) từ mô tả kiến trúc bằng ngôn ngữ tự nhiên: "Tôi cần 1 EKS cluster, 3 microservices, RDS PostgreSQL và Redis cache" → AI tự viết Terraform modules, Helm charts và Kubernetes manifests hoàn chỉnh. Kết hợp review tự động bằng Checkov AI.
  Target role: DevOps, Cloud Engineer, Platform Engineer
  Từ khoá: IaC AI generator, Terraform AI, Kubernetes YAML AI, infrastructure automation

---

Bài 36:
  Tiêu đề: CI/CD Pipeline Thông minh với AI: Tự động Optimize Build Time, Detect Flaky Test và Security Scan
  Mô tả: Nâng cấp CI/CD pipeline với AI Agent: tự động phát hiện và bỏ qua flaky test, tối ưu thứ tự build step dựa trên lịch sử, tích hợp AI-powered SAST/DAST (Snyk AI, Semgrep), và tự động generate release notes từ commit message. Hướng dẫn tích hợp vào GitHub Actions và GitLab CI.
  Target role: DevOps, Developer, Tech Lead
  Từ khoá: AI CI/CD pipeline, flaky test detection AI, AI security scan, release notes generator

NHÓM 7: AI AGENTS NÂNG CAO & XU HƯỚNG TƯƠNG LAI (Bài 37)
====================================================================

Bài 37:
  Tiêu đề: Xây dựng "Digital Twin" cho Team IT: Mỗi thành viên có một AI Agent phản ánh chuyên môn của mình
  Mô tả: Khái niệm Digital Twin trong đội ngũ IT: mỗi member xây dựng một AI Agent được train trên knowledge, coding style, review pattern và decision-making của chính họ. Khi họ vắng mặt, agent có thể trả lời câu hỏi, review code và đưa ra gợi ý theo đúng "phong cách" của người đó. Thảo luận cả về triển vọng lẫn rủi ro đạo đức.
  Target role: Toàn bộ IT team, Tech Lead, CTO
  Từ khoá: digital twin AI, personal AI agent, team knowledge preservation, AI persona
